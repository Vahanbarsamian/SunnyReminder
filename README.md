## 🌟 Concept

L'application surveille votre agenda (Google Calendar et autres) et déclenche une scène de plage interactive à chaque échéance. Un avion de tourisme survole alors le paysage en traînant une banderole avec le titre de votre rendez-vous.

## ✨ Fonctionnalités Majeures

### 1. Design "Living Landscape" (Paysage Vivant)
- **Profondeur 3D** : Un moteur graphique avec effet de parallaxe. Le premier plan et l'horizon bougent à des vitesses différentes.
- **Météo Dynamique** : Le ciel s'adapte en temps réel à votre météo locale (Soleil ☀️, Nuages ☁️, Pluie 🌧️ ou Orage ⛈️).
- **Détails HD** : Palmier texturé réactif au vent, mer scintillante, voiliers en mouvement et nuées de mouettes.

### 2. Le Meeting Aérien 🛩️
- **File Indienne** : Si plusieurs rendez-vous sont proches, une parade d'avions de couleurs différentes défile à des altitudes variées.
- **Détails "Expert"** : Avions monomoteurs avec hélices tournantes, trains d'atterrissage et stabilisateurs détaillés.
- **Lisibilité** : Banderoles stables et adaptables à la longueur du texte.

### 3. Secrets de la Plage (Interactions) 🆘
- **☀️ Soleil** : Appuyez dessus pour fermer le rappel (Bouton OK).
- **🏖️ Serviette** : Ouvre votre calendrier et fait sortir un petit crabe orange 🦀.
- **🏰 Sable** : Un appui long construit instantanément un château de sable.
- **🍦 Stand de Glaces** : Reporte l'alerte (Snooze) selon un délai ajustable.

### 4. Personnalisation & Fiabilité
- **Sons Système** : Choisissez n'importe quelle sonnerie de votre téléphone pour l'alerte.
- **Aura LED** : Un halo lumineux pulsant (couleur au choix) simule la LED de notification sur les téléphones modernes (comme le Samsung S25 Ultra).
- **WakeLock** : Technologie garantissant le réveil du téléphone même en sommeil profond.
- **Dashboard Expert** : Menu centralisé pour gérer les autorisations Android 14+ (Plein écran, Alarmes exactes, etc.).

## 🚀 Installation

1. Clonez ce repository.
2. Ouvrez le projet dans **Android Studio**.
3. Compilez et installez l'APK (`app-debug.apk`).
4. **Important** : Suivez le guide du "Porte-Voix" dans l'application pour accorder les permissions nécessaires (Notifications, Alarme, Calendrier, Plein Écran).

## 🛠️ Technologies
- **Langage** : Kotlin
- **UI** : Jetpack Compose (Canvas API)
- **Background** : WorkManager, AlarmManager
- **Data** : CalendarProvider (Instances API)
