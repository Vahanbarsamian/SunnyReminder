# Walkthrough - Compte à rebours visible & Version 2.8 🏖️🚀🔢

Cette mise à jour apporte le compte à rebours interactif pour le test et passe officiellement le logiciel en version **2.8**.

## Nouveautés de cette version

### 1. Compte à rebours "Ignition" 🚀
- **Interactivité** : Le bouton de test (5s) affiche désormais un décompte en temps réel directement sur le bouton.
- **Séquence** : Vous verrez défiler : `5...`, `4...`, `3...`, `2...`, `1...` puis le message final `ignition :)` juste avant que la plage ne s'affiche.
- **Ergonomie** : Le bouton est désactivé pendant le décompte pour éviter les lancements multiples.

### 2. Passage à la Version 2.8 🔢
- **Identité** : Le numéro de version a été mis à jour partout dans l'application :
    - Menu des réglages (**À propos**).
    - Bas du Dashboard.
    - Fichiers de configuration système (Gradle).

### 3. Documentation & Aide 🆘📝
- **Dialogue d'Aide** : Une nouvelle entrée "🚀 Test" a été ajoutée dans le menu d'aide (?) pour expliquer le nouveau décompte.
- **README.md** : Le fichier sur GitHub a été mis à jour avec le nouveau numéro de version et le lien de téléchargement.

## Comment tester le décompte

1. Restez sur l'écran d'accueil (**HomeScreen**).
2. Repérez le bouton bleu en bas : **"Lancer le test (5s)"**.
3. Appuyez dessus et admirez la séquence de lancement `5...4...3...2...1...ignition :)`.
4. La plage s'ouvrira automatiquement à la fin du décompte.
